# Plan de comida · Nacho y Teresa

App web para el plan de alimentación: lo que toca hoy, calendario con rotación de 3 semanas, recetas con macros por persona, modo cocina y lista de la compra de Mercadona sincronizada entre los dos.

- `index.html`: la app completa.
- `config.js`: configuración de sincronización (Firebase Firestore).
- `manifest.webmanifest` e iconos: para añadirla a la pantalla de inicio del iPhone.

Publicada con GitHub Pages.
